# App Growth Studies

An independent portfolio by Sriram Naidu Thota for an Apple Ads platform specialist role. It is not an Apple product or an official Apple interface.

## Direction
Apple-inspired editorial clarity around a working analytics product. White and silver (#f5f5f7), near-black (#1d1d1f), secondary text (#65656b), and one blue accent (#0071e3). Green and amber communicate analytical status only. Native system font stack uses the platform's installed interface font; no Apple fonts are redistributed. Tabular numerals for metrics. No stock imagery; analytical charts are the visual subject.

## Layout
Maximum width 1240px. A 64px translucent navigation bar. A confident, spacious portfolio overview leads into two working cases. Application screens are denser, with compact filters, open metric rows, and tables. Panels use 20px corners; controls use 10px corners; status badges and primary calls to action use pills. Comfortable 8px spacing scale. Mobile stacks filters and panels; wide tables scroll inside named regions.

## Behavior
Hash routes support GitHub Pages. Every visible control performs a real action. Filters share a consistent analysis scope; selected-row evidence uses that same scope. All metrics derive from additive counts. Scenario projections are explicitly hypothetical, never causal claims. No login, keys, tracking, or persistence of visitor data. Respect reduced motion and visible keyboard focus.

## Verification
Test count reconciliation, weighted ratios, zero denominators, low-volume recommendations, account ranking, conserved scenario budgets, routes, filters, exports, mobile overflow, and client-review navigation. Source and assumptions stay one click away.
